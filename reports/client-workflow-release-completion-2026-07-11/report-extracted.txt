Data and migration design
The old one-order-per-quote constraints were removed only after new order ownership fields were added and legacy records were backfilled. New
orders use a serializable transaction and optimistic remaining-quantity update. This prevents two staff members from allocating the same quote balance
and prevents a client retry from creating a duplicate order.

Residual release risk
Dependency follow-up The targeted Nodemailer upgrade to 9.0.3 is included. The latest npm production audit still reports three high and several
moderate advisories in legacy Nest GraphQL/WebSocket and Next bundled dependency paths. npm’s automated remedy recommends invalid major
downgrades, so it was not applied. The production API exposes only POST GraphQL, disables Playground in production, restricts origins, and does not
enable subscriptions; however, a planned framework dependency upgrade remains required for a clean audit.
Asset durability The code validates images and supports a configured persistent directory. Railway ephemeral storage is not suitable for durable
product images unless the image directory is mounted persistently or replaced with object storage before the production rollout.
Earlier local user snapshot
The prior read-only audit of the configured local Marble Park database found 98 users: 37 active and 61 inactive. All 751 stored sessions were expired
at that audit time. This is a local snapshot, not a current production count; production data remains unverified until Railway is restored and accessed
under the deployment runbook.
